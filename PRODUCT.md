# Product

## Register

product (panel admin / dashboards / tablas) con una superficie **brand** secundaria (landing pública + ficha de producto, donde el diseño ES el producto).

## Users
- **Personal de la boutique** (Super Admin, Administradora, Cajera, Vendedora, Inventario): trabajan a diario gestionando inventario, alquileres 50/50, pagos, facturas y devoluciones. Contexto de escritorio, ritmo rápido, necesitan densidad de datos fiable y acciones claras.
- **Clientas/novias y acompañantes**: visitan la web pública para descubrir piezas, verificar disponibilidad por fecha y solicitar un alquiler. Contexto emocional (su evento), mayormente móvil.

## Product Purpose
Operar una casa de novias: alquiler y venta de vestidos de novia, vestidos de gala, trajes y accesorios. El panel administra disponibilidad por fecha (sin reservas duplicadas), el flujo de pago 50% inicial / 50% al retirar, facturación, contratos y reportes. La web pública convierte visitas en solicitudes de alquiler. Éxito = operación sin choques de fechas, cobro completo, y una web que transmite confianza y lujo.

## Brand Personality
Elegante, nupcial, confiable, atemporal. Tres palabras: **refinada, cálida, segura**. El panel debe sentirse como una herramienta profesional impecable (que desaparece en la tarea); la web debe emocionar y dar estatus de boutique de lujo.

## Anti-references
- Plantillas SaaS genéricas "cream + slate" sin personalidad.
- Dashboards con la plantilla hero-metric (número gigante + gradiente) repetida.
- Landing tipo editorial-magazine clonada (serif italic + drop caps + rejilla de periódico) sin imágenes.
- Tablas/botones inconsistentes pantalla a pantalla; fuentes display en datos/labels.

## Design Principles
1. **La herramienta desaparece en la tarea** (panel): familiaridad ganada, estados completos, color sólo para acción/estado.
2. **La web emociona** (brand): imagen protagonista, color comprometido (negro + rojo Londres), tipografía con jerarquía marcada.
3. **Una sola voz visual** en todo: misma paleta, mismos componentes, mismos badges.
4. **Datos reales y verificables**: cada métrica/gráfico sale de una consulta real; nada decorativo que mienta.
5. **Identity-preservation**: la marca ya comprometió Fraunces + Plus Jakarta + rojo/dorado; se respeta y se refina, no se reinventa.

## Accessibility & Inclusion
- Texto de cuerpo ≥ 4.5:1 de contraste; nada de gris claro sobre crema para "elegancia".
- Foco visible en controles; objetivos táctiles ≥ 40px en móvil.
- `prefers-reduced-motion`: alternativa sin movimiento para reveals y gráficos.
- Estados de carga, vacío y error en cada superficie con datos.
